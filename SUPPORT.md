# Support

This plugin is provided as-is so the community can fork and maintain it. There is no paid or guaranteed support.

## Where to get help

- **Bugs and unexpected behavior:** open a [bug report](https://github.com/ronalfy/archive-pages-pro/issues/new?template=bug_report.md).
- **Ideas and enhancements:** open a [feature request](https://github.com/ronalfy/archive-pages-pro/issues/new?template=feature.md).
- **Security:** see [SECURITY.md](SECURITY.md). Do not post exploit details in a public issue.
- **Development questions:** see [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md).

WordPress.org support forums are not the primary channel for this GitHub project.
